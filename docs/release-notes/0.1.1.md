# xatodo 0.1.1

Fix release for the connect package.

## What changed

- The connect package now declares its required config fields
  (`backend.endpoint`, `backend.apikey`) in the manifest. In 0.1.0 the
  declaration was missing (`config: null`), so the shell rendered an empty
  config page — there was nowhere to enter the daemon address, and the
  connector could not serve. The shell now gates the first start on the
  required fields and renders the daemon settings (endpoint + API key,
  labels in English and Chinese) directly on the component config page.
- A packaging-time proof rejects any future connect package without the
  declaration.

## Upgrading from 0.1.0

Re-import the new `xatodo-connect-0.1.1.zip` over the installed one (same
component id — the replacement keeps your edited `config.toml`); fill in
the daemon endpoint and API key on the config page, then start.
