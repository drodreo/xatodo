## Fixes

### Connector: save-config no longer fails with 404

Saving the connector's configuration from the shell previously failed with "component config endpoint returned 404". The connector now mounts the standard `/config` endpoint: its manifest carries the config declaration (compiled in from the same file the packaging chain weaves into the shipped manifest, so the two can never drift), and the config integration writes values back to `config.toml` — which the connector reads on its next start. A serving instance now answers `GET /config` and persists `PUT /config` changes; this path is pinned by a regression test.
