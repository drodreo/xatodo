## Fixes

### Connector diagnostics: full URLs in failure logs

Forward and events-bridge failures now log the complete backend URL they were dialing (previously only the request path, which hid the actual target), and startup logs the configured endpoint plus proxy mode. Misconfigured or proxy-redirected backends are now visible at a glance.

### Note for 0.1.2 users

0.1.2's connector followed the OS system proxy by default; 0.1.3+ default to a direct connection (configurable). If a 0.1.2 connector cannot reach a LAN daemon, upgrade — this release's logs will name the exact target on any failure.
