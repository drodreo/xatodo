## What's New

### Daemon: `/events` live-update stream

The daemon now serves `GET /events` — an NDJSON stream that pushes one `update_dataModel` line after every successful create/update/delete (`surfaceId=xatodo`, `path=/todos`), under the same Bearer apikey auth as the REST/MCP plane. The connect form's live-refresh bridge no longer reconnects forever against a 404: connected clients now see todo changes land in real time.
