## Changes

### Fixed the in-shell UI rendering (surface → module)

The packaged component previously declared its UI as the `surface` form
(`ui_type: "surface"`, entry `surface.json`), so the superlive shell rendered
a generic table from the A2UI descriptor instead of the real React UI. The
manifest now declares the `module` form (`ui_type: "module"`, entry
`entry.js`): the shell mounts the actual React bundle inside the component
route, matching what the build produces all along.

### Aligned the API namespace with the component identity

The UI's gateway prefix was `/api/todo` while the component's registered
namespace is `xatodo`; in-shell API calls were dispatched to a namespace the
component never registered. Every reference now uses `/api/xatodo` (the ui
`apiClient` prefix constant, and the packaging scripts' namespace constant
and artifact assertion), so the shell strips the segment the component
actually serves under.

### Removed the retired surface descriptor

`ui/public/surface.json` is deleted: nothing consumes it in the module form,
and it was the descriptor that made the shell render the generic table.

### Single source of truth for the packaged ui declaration

`scripts/gen-manifest.py` reads its `ui_type`/`entry` defaults from the
repo-root `manifest.json` `ui` section; an explicit CLI value disagreeing
with the repo-root declaration is a hard error instead of a silent drift.
The packaging scripts' identity note now states the namespace contract
accurately (namespace = manifest.namespace, must equal id/COMPONENT_ID; it
is not a `/health` self-report).
