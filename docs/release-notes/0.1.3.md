# 0.1.3

Connect-form usability batch.

- **Optional proxy toggle** — the connector's outbound client reaches the daemon directly by default (ambient `http_proxy` env ignored, both the REST/MCP forwarding and the events bridge); a new `backend.use_system_proxy` setting (boolean, default off, rendered on the shell's component config page) opts into ambient proxy settings for networks that require one. Forward failures now report the full error source chain instead of reqwest's ambiguous top-level string.
- **Post-install flow fix** — the bundled config ships the required backend fields empty, so a fresh install lands on the config page before its first start (non-empty placeholders used to skip that step and start the connector on placeholder values).
- **Localized component name** — the manifest carries `{zh, en}` menu/route titles; the component now displays 待办 / Todos following the shell's UI language. Both install forms share the same display name.
- **Update-check declaration** — package manifests declare their form's version manifest (served as `releases/latest/download/{form}-latest.json`); the release workflow publishes those manifests alongside the platform zips. Components declaring an update manifest get the shell's update-check button (requires a shell build with the update mechanism).
